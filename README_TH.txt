BOSSMASTER Display 1.1.0

ธีมลูกสำหรับ KolorTube ที่เปลี่ยนเฉพาะชั้นแสดงผล โดยคงข้อมูลเดิมทั้งหมด:
- โพสต์ รูปปก โปสเตอร์ และแกลเลอรี
- นักแสดง ค่าย หมวดหมู่ และแท็ก
- ตัวเล่นวิดีโอและตำแหน่งโฆษณาของ KolorTube
- ระบบ WP MY BOSS และ UNI Import

สิ่งที่เพิ่มและแก้ใน 1.1.0:
- คืนเมนู Copyright ใน รูปลักษณ์ > ปรับแต่ง และใช้ค่า copyright_content เดิม
- Footer แสดงข้อความ Copyright ที่แก้ไขได้จริง พร้อมลิงก์ ตัวหนา และข้อความบรรทัดเล็ก
- แก้โหมดสว่างให้ชื่อเรื่อง เนื้อหา หัวข้อ Gallery เรื่องที่เกี่ยวข้อง การ์ด Header และ Footer อ่านได้ครบ
- หน้าแรกปรับให้เหมือน BOSSMASTER Interactive Preview มากขึ้น
- Hero แยกข้อความเน้นสีชมพู + การ์ดซ้อน 3 ใบ + แถบทางลัด 3 ช่อง
- เรื่องเด่นเป็นสไลด์แนวนอน 5 การ์ด มีปุ่มก่อนหน้า หยุด และถัดไป
- วิดีโอล่าสุดใช้จังหวะการ์ดขนาดใหญ่ 3 คอลัมน์บนคอมพิวเตอร์
- เลือกดูตามความสนใจเป็น 5 ช่องในแถวเดียวบนจอใหญ่
- เพิ่มแผงตั้งค่าลอย WP MY BOSS ด้านขวา เลือกชุดสี รูปแบบการ์ด ความหนาแน่น และเปิด/ปิดบล็อกหน้าแรก
- ปุ่ม “บันทึก WordPress จริง” บันทึกค่า Theme Mod ได้ทันทีสำหรับผู้ดูแล
- รองรับ Desktop / Tablet / Mobile และ Gallery Lightbox

วิธีติดตั้งอัปเดต:
1. สำรองฐานข้อมูลและ wp-content ก่อน
2. ติดตั้ง WP MY BOSS 3.2.2 โดยอัปโหลด ZIP แล้วเลือกแทนที่เวอร์ชันเดิม
3. ติดตั้ง BOSSMASTER Display 1.1.0 โดยอัปโหลด ZIP แล้วเลือกแทนที่เวอร์ชันเดิม
4. ไปที่ รูปลักษณ์ > ปรับแต่ง
5. เมนู Copyright จะอยู่ระดับเดียวกับ เมนู, วิดเจ็ต และ CSS เพิ่มเติม
6. ล้างแคช LiteSpeed/Cloudflare และกด Ctrl+F5 หนึ่งครั้ง

หมายเหตุ:
- ไม่ลบหรือแก้ระบบ SEO
- ไม่แก้ข้อมูลใน UNI Import
- ไม่แก้โพสต์ รูป นักแสดง ค่าย หมวดหมู่ หรือแท็ก
- แผงตั้งค่าลอยจะแสดงเฉพาะผู้ใช้ที่มีสิทธิ์แก้ไขธีม


อัปเดต 1.1.1
- หน้ารายละเอียดแสดงหมวดหมู่เพียง 1 จุดในรูปแบบ “หมวดหมู่ : ชื่อหมวดหมู่”
- ตัดหมวดหมู่ออกจากบรรทัด CODE, กล่องข้อมูลโปสเตอร์ และชุดแฮชแท็ก เพื่อไม่ให้ซ้ำ
- เพิ่มเมนู BOSSMASTER Display > หน้ารายละเอียดและหมวดหมู่ ให้เปิด/ปิด เปลี่ยนข้อความ และปรับสีกล่องได้
- กล่องหมวดหมู่ใช้โทนสีอ่อน ไม่ใช้พื้นชมพูเข้ม

อัปเดต 1.1.2
- หน้ารายละเอียดปรับตามโครงต้นแบบ BOSSMASTER แบบการ์ดแนวกว้างและโหมดกระชับ
- หมวดหมู่เหลือ 1 จุด และบล็อกป้ายเดิมจาก AV Framework PRO จะไม่แทรกซ้ำ
- เพิ่มปุ่มถูกใจ บันทึก คัดลอกลิงก์ และรายละเอียดรหัส/นักแสดง/ค่าย/วันที่ใต้โปสเตอร์
- ตั้งค่าได้ที่ รูปลักษณ์ > ปรับแต่ง > BOSSMASTER Display > หน้ารายละเอียดและหมวดหมู่
